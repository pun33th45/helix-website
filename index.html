Features

Everything you need to build

A fast desktop editor with AI workflows, terminal access, and provider choice built into the core experience.

Core

Streaming AI Chat

Token-by-token responses from Gemini, Groq, or OpenRouter. Attach files, reference code, apply edits directly.

Core

Monaco Editor

The same editor engine powering VS Code. 50+ languages, IntelliSense, syntax highlighting, minimap.

Core

Integrated Terminal

Full xterm.js terminal with PowerShell/Bash. Multiple tabs, resizable, runs in your workspace root.

Core

Command Palette

Ctrl+Shift+P for commands, Ctrl+P for files. Fast fuzzy search across your entire workspace.

AI

Inline Completions

Ghost text suggestions as you type. Tab to accept, Escape to dismiss. Powered by fast Gemini Flash.

Free

Bring Your Own Key

Works with Gemini, Groq, or OpenRouter. Your key, your data, no subscriptions.
